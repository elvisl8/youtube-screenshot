说明与边界

受 DRM 保护的视频截不了：Netflix、Disney+、YouTube 付费电影等带 DRM 的内容，浏览器会把画面挡成黑屏，这是行业统一限制，任何插件都绕不过去。普通 YouTube 视频（包括 4K）不受影响。
字幕：干净帧里本来就不含字幕（字幕是网页叠上去的，不是视频画面的一部分）；要带字幕请用「所见即所得」并把字幕打开、全屏播放时截。
  • Shorts 页面同样能截（竖屏原生分辨率）。
  • 暂停状态也能截，截的就是停住的那一帧。
  • Safari 版：本插件是标准 Web Extension 源码，可用 Xcode 的 safari-web-extension-converter 转换，步骤见安装包 README 的 Safari 一节。
